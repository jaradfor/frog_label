# Demo and tutorial audio provenance

The demo and tutorial use a real adult male Green Treefrog (`Hyla cinerea`) recorded at the University of Mississippi Field Station on June 13, 2014.

- Repository asset: `src/assets/green_tree.mp3`
- Source: [Hyla cinerea call audio.ogg](https://commons.wikimedia.org/wiki/File:Hyla_cinerea_call_audio.ogg)
- Recordist: Wikimedia Commons user [Fredlyfish4](https://commons.wikimedia.org/wiki/User:Fredlyfish4)
- License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- Original SHA-256: `627f68f34cb0d641c8c81473cfa43d32383e1ea507702639ed0f57142d8bef61`
- FrogLabel excerpt SHA-256: `0f7e992fad605105bce9a8b0aa183a517bd69f256a87861a64d6d1679758b830`

FrogLabel uses seconds 12.5–24.5 of the original recording. The excerpt was converted from Ogg Vorbis to 96 kbps stereo MP3 at 48 kHz, stripped of container metadata, and given 50 ms edge fades. These changes make the clip compact and avoid clicks while preserving the recorded calls. The excerpt remains licensed under CC BY-SA 3.0.

`public/audio/synthetic-frog-practice.wav` remains a CC0 deterministic signal for automated decoder and performance tests. It is not presented to annotators as a frog recording.
