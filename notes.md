# Notes

FrogLabel no longer depends on Wavesurfer. Playback uses the browser media element; the
waveform and complete-window STFT spectrogram are rendered from FrogLabel's cached analysis
decode. Playback-rate changes therefore do not rebuild or rescale scientific coordinates.

Current verification evidence is generated by the unit/property suites and locally hosted
Playwright workflows described in `docs/TESTING_AND_UPGRADES.md`; this file does not preserve
claims from the retired baseline implementation.
